# AI Resume Analyzer

An AI-assisted resume analysis tool that compares a resume with a job
description and provides a similarity score, matching keywords,
missing keywords, and basic suggestions.

## Features

- Upload resume in PDF format
- Paste job description
- Extract resume text
- Calculate resume-job similarity
- Identify matching keywords
- Identify missing keywords
- Provide basic improvement suggestions

## Tech Stack

- Python
- Streamlit
- Scikit-learn
- PyPDF
- Pandas
- NumPy

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
